# Проект SkyPro_Bank

## Описание:

Проект SkyPro_Bank - это программа для анализа банковский действий, которая пишется учениками курса SkyPro

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/hatber91/SkyPro_Bank.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. На данном этапе программа ещё в разработке. Данное меню будет расширено и обновлено в следующих версиях.

## Тестирование:

В проекте настроено тестирование с помощью `pytest`.

Для запуска тестов выполните команду:

```
pytest
```
Тестами покрыты основные функции проекта:

- маскирование номера банковской карты; 
- маскирование номера счёта; 
- обработка входной строки с картой или счётом;
- преобразование даты в формат ДД.ММ.ГГГГ;
- фильтрация операций по статусу;
- сортировка операций по дате;
- фильтрация транзакций по валюте;
- генератор описаний транзакций;
- генератор номеров банковских карт.

В проекте протестированы:

- корректная работа генераторов;
- обработка пустых списков;
- проверка крайних значений диапазонов;
- корректность форматирования данных;
- обработка случаев отсутствия совпадающих значений.

### Также в проекте используется:
- mypy — для проверки типизации;
- flake8 — для проверки качества и стиля кода.
